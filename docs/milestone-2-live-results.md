# Milestone 2 — תוצאות בדיקות AI חיות

> **בדיקות חיות**: פניות אמיתיות ל־OpenAI דרך השרת המקומי, בקלט סינתטי בלבד. הן נפרדות מהבדיקות האוטומטיות (`npm run check`), שמשתמשות ב־Mocks בלבד ואינן פונות ל־AI.

- **תאריך:** 21 באוקטובר 2026
- **מודל:** `gpt-6-luna` (OpenAI ישירות), Reasoning `none`, Moderation `omni-moderation-latest`
- **כלי:** `node scripts/live-check.mjs` מול `npm run dev`
- **זמן תגובה:** 1.1–2.6 שניות לבקשה
- **עלות משוערת:** כ־420 Input Tokens וכ־45 Output Tokens לבדיחה, כלומר שבריר של סנט לכל ההרצה

ההרצה שלהלן היא ההרצה הסופית, אחרי חיזוק הוראת העברית (ראה „ממצאים”).

## ממצאים

- **נושא בשפה זרה:** בהרצה הראשונה, הנושא בצרפתית הסתיים ב„לא הצלחנו ליצור בדיחה”. בדיקה ישירה הראתה שהמודל ענה לפעמים בצרפתית, ובדיקת העברית בשרת חסמה את התשובה, כפי שתוכנן. לאחר חיזוק ההוראה (התשובה תמיד בעברית, והקלט מסומן „write the joke in Hebrew”), 18 מתוך 18 ניסיונות בנושאים בצרפתית, אנגלית וספרדית החזירו עברית.
- **ניסיונות Injection:** חלקם נדחו, וחלקם קיבלו בדיחה נקייה שמתעלמת מההוראה שבנושא. בשני המקרים לא הוצג תוכן אסור.
- **מגבלה:** אלה בדיקות מדגמיות. שילוב הוראות היצירה, Moderation ובדיקות השרת **אינו מבטיח סינון מוחלט**, והמודל עשוי לענות אחרת בהרצות אחרות.

## בדיקות נוספות בדפדפן ובשרת (ידניות)

- מצב פתיחה „בדיחה יומית” וכרטיס ריק. במהלך הבקשה מוצג „מכינים לכם בדיחה…” והטופס מושבת. אחרי ההצלחה הכותרת הופכת ל„הבדיחה שלכם”. Enter מפעיל יצירה. דחייה מוצגת בתוך הכרטיס.
- לחיצה כפולה בזמן ההמתנה שולחת בקשת POST אחת בלבד.
- הדפדפן פונה רק ל־`localhost:3000`, כולל הגופנים. אין פנייה ל־OpenAI או ל־Google.
- המפתח אינו מופיע ב־Client Bundle (`.next/static`).
- לוג השרת כולל רק requestId, קוד, זמן ו־Tokens, בלי נושא ובלי בדיחה.
- Origin זר מקבל 403, Content-Type לא JSON מקבל 415, ו־GET מקבל 405. כל התגובות כוללות `Cache-Control: no-store`.
- השוואה חזותית ל־Mockup נעשתה ברוחב מובייל (375px) וברוחב מסך רחב (1280px, טור של 480px).
